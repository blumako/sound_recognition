# sound_recognition
speech emotion recognition using sklearn and librosa libraries
trains/tests on audio files from the RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song) data set to predict speech emotion
predicts speech emotion with up to 77% accuracy
